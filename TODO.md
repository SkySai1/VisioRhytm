# VisioRhytm: MVP и целевая архитектура

Разработка идёт от музыкальной модели к аудиодвижку и затем к UI.
Статусы обновляются после сборки и проверок, а не по наличию заглушек.

## MVP

- [x] Domain: versioned Project, musical ticks (PPQ 480), независимые позиции и длительности.
- [x] RhythmEngine: размеры 4/4, 3/4, 6/8, 12/8; сетки 1/4, 1/8, 1/16; BPM 40–240.
- [x] MetronomeEngine: аудиорендер, primary/secondary/regular/subdivision клики, громкость.
- [x] Audio clock: единый источник позиции для звука и визуализации; без музыкального Timer.
- [x] LyricsEngine: строки, слова, эвристическое русское слогоделение.
- [x] Ручная корректировка границ слогов с сохранением исходного текста.
- [x] Автоматическая равномерная раскладка по ticks.
- [x] SwiftUI Canvas: такты, доли, subdivisions, номера, колонки и playhead.
- [x] Индивидуальные 1/2/4 такта, непрерывная плотность, редактирование и reset строк.
- [x] Нейтральная оценка плотности и сравнение соседних строк.
- [x] BPM не меняет layout; размер меняет сетку, сохраняя позиции.
- [x] Scroll и zoom.
- [x] Play/Stop/Return, цикл по выбранным тактам.
- [x] Codable JSON, проверка версии и входных данных, save/open, локальное autosave.
- [x] Сборка debug/release, тесты модели, раскладки, persistence и аудиочасов.
- [x] README: требования, сборка .app, запуск, пользовательский сценарий, ограничения.
- [ ] Проверка слухом и глазами на реальном аудиоустройстве после нескольких минут playback.

## Целевая архитектура

- [x] Domain остаётся независимым от SwiftUI и AVFoundation.
- [x] RhythmEngine — единственное место расчётов ticks, beats, bars, BPM и density.
- [x] LyricsEngine использует заменяемый SyllabificationService для новых языков.
- [x] MetronomeEngine владеет audio render clock; UI лишь читает musical position.
- [x] ProjectStore отвечает за версионирование, валидацию и атомарное сохранение.
- [x] UI: MainWindow, TransportBar, RhythmSettingsPanel, LyricsEditor, RhythmCanvas,
  LyricsTrack, SyllableBlock, LineControls, Inspector.

## После MVP

- [ ] Drag/stretch слогов, паузы и переносы: ticks + snap Off/1/4/1/8/1/16.
- [ ] Undo/redo и история ручной раскладки.
- [ ] Ударения; улучшение русской эвристики; сервисы других языков.
- [ ] Section markers Verse/Chorus/Bridge и сохранение пустых строк как секций.
- [ ] Статистика сравнений, групповые операции со строками.
- [ ] Экспорт click track / аудио и AI-specific presets.
- [ ] Миграции будущих версий JSON.
- [ ] Дистрибуция: иконка, Developer ID, notarization, универсальный binary, CI.
- [ ] Профилирование долгих проектов, доступность VoiceOver, UI-автотесты.

MIDI, pitch, ноты, гармония, DAW, вокальный синтез и сетевые AI-сервисы
не входят в MVP.
